# dep-componentized-filesystem-chroot

From [componentized filesystem](https://github.com/componentized/filesystem): [`chroot`](https://github.com/componentized/filesystem/tree/v0.2.1/components/chroot), wasi:filesystem limited to the directory of the `path` key in wasi:config, pulled from `ghcr.io/componentized/filesystem/chroot:0.3.1`. There is no debug build of this version, the debug build is the release build.
