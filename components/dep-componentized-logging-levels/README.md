# dep-componentized-logging-levels

From [componentized logging](https://github.com/componentized/logging): [`levels`](https://github.com/componentized/logging/tree/v0.2.1/components/levels), a virtual logger that selectively emits log events based on the context and level, pulled from `ghcr.io/componentized/logging/levels:0.3.1`. There is no debug build of this version, the debug build is the release build.
