# dep-componentized-static-config-factory

From [componentized static-config](https://github.com/componentized/static-config): [`factory`](https://github.com/componentized/static-config/tree/v0.2.0/components/factory), creates wasi:config components with static values, from key value pairs, pulled from `ghcr.io/componentized/static-config/factory:0.2.0`. There is no debug build of this version, the debug build is the release build.
